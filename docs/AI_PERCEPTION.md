# 0.17 敌人感知与投石

巡逻时按朝向、距离和遮挡判断视野；蹲伏缩小被发现距离，冲刺在12米内产生可听见的位置。看见玩家后记住最后位置6秒，失去视野后前往该位置并搜索，不能继续读取躲在遮挡物后的玩家新位置。攻击失去视线时中止蓄力。

G消耗一块实际石头，沿镜头方向抛向约10米处，飞行轨迹逐帧检测墙体碰撞。落点在18米内产生声响，未发现玩家的敌人会前往调查；已经看见玩家且仍有追击记忆的敌人不会立刻被石头转移。石块与敌人均随菜单暂停，新游戏/读档会清除临时石块和声响。投掷不是伤害攻击。

关闭菜单后短暂忽略鼠标位移，防止指针重新捕获时镜头突然转动。

验证入口：tools/test-ai.ps1 -Executable build/BeyondTheMistline.exe。受控场景提供墙体、敌人和石头，用于验证规则，不作为正常获取物资、人工潜行体验或整局难度验收。AI_TEST覆盖实际绕墙接近、攻击预警与正面格挡；PERCEPTION_LIVE覆盖引擎G输入、扣料、落点调查、飞行撞墙、菜单暂停、空包拒绝、新游戏清理和镜头重新捕获。基础回归另校验记忆衰减和遮挡后位置不更新。

测试中曾误用3米墙验证高抛轨迹，以及在镜头尚未转到位时投掷；改为高于轨迹的6米墙，并等待镜头稳定后检查。没有据此降低碰撞要求。

仍待人工验证：两种敌人在全部建筑/坡地的潜行实战、多敌人围攻、长时间搜索表现和最终动画。0.16录制失败的结果仍保留，未因这次改动改记为通关。
