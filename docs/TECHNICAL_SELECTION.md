# 雾线之外 技术选型

2026-11-22。采用 Godot 4.5.2 stable、GDScript、Compatibility OpenGL 3 渲染。官方 Windows x64 引擎与同版本导出模板；游戏导出为独立 EXE 与 PCK，无需安装编辑器。版本固定以保持构建可重复，不以版本最新为目标。

选择理由：当前为空工程，Godot 可在本机通过命令行完成场景生成、碰撞、物理、UI、独立打包和自动化回归。相比自建渲染器可将时间集中于生存循环。初版地图缩至约 420 米见方，优先保证内容密度。

地形：程序三角网格、连续高度函数、静态碰撞；生态分区植被与地标。角色及动物先采用自主程序模型与关节动画；后续以实际画面质量决定替换资产，不将初期模型当作最终美术验收通过。

美术方向：冷青海岸、灰绿松林、铁锈工业建筑，灯塔与篝火使用暖琥珀色。研究海岸灯塔、北欧松林、废弃港口、潮间带和户外生存装备；网络参考只用于构图与配色，不直接复制为资产。

存档使用 user:// 下 JSON，原子替换，保留资源、建筑、任务和状态。性能目标 1080p 60 FPS，尚未实测，不作性能承诺。首版以本机真实运行结果记录兼容性与帧率。

官方依据：https://godotengine.org/download/archive/ ，https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html
