# 完整主线引导流程验证

2026-11-23，独立发布EXE的引擎输入引导流程已完成整章，MAINLINE_OK，退出码0且日志无错误。不要将它扩展为人工盲测、30–60分钟首次体验或整体成品通过。

mainline_test.gd 从新游戏开始，通过引擎键鼠事件采集出生物资、制作石斧和篝火、搜索渔村/仓库/工厂/灯塔补给、制作工作台和维修用品，并尝试修复灯塔、研究所和通讯站。没有发放物资、传送角色、关闭敌人或直接设置任务完成状态。路线由导航网格引导，属于知晓地图的自动引导流程，不是盲测或人工游玩。

已遇到的失败：

- 第一轮持续步行，在敌人追击中死亡，且控制器复活后仍试图前往旧路径点。增加死亡即失败检查与正常冲刺避险。
- 第二轮到达灯塔并完成维修用品制作，但在研究所前死亡。控制器每两米停顿，降低了有效逃跑速度；已有布料只制作一条绷带。改为连续经过可见通行路径、在真实材料范围内备足最多三条绷带。没有降低敌人伤害或关闭追击。
- 终端与设备为实际碰撞物体，控制器需走到合理交互距离，不能要求角色站到碰撞物体中心。已使用其前方1.5米作为接近点。

测试脚本 tools/test-mainline.ps1 会启动独立发布EXE，要求MAINLINE_OK且退出码为0、日志无错误，超时13分钟会明确失败。发布日志可能在进程结束时才刷新，不能因暂时空白就推断终止或重新启动；可结合存档修改时间与当前进程句柄确认进展。

本轮正式结果位于 build/mainline-release.log：约185.761秒完成。实际存档记录三处设施均恢复，角色生命98.81；mainline-complete.png展示任务章节完成。该控制器知晓地图、配方和目标，不能据此声称新玩家首次游玩时长达标。此前失败保留在开发日志mainline.log，未被计作通过。

修复设施的世界反馈已加入：控制台状态色、灯塔恢复亮度和通讯塔信号灯。SIGNALS_OK验证完成与未完成的灯光/控制台状态，使用浮点近似比较。尚未据此宣称最终视觉品质通过。

录屏入口：tools/test-mainline.ps1 -RecordVideo，使用Godot内置Movie Writer记录真实引擎输入流程；录制使用隔离数据目录并在画面标注“引擎输入引导流程 / 非人工盲测”。编码入口 tools/encode-gameplay.ps1 将完整录制的前300秒压缩为MP4。录制已结束，结果与限制见下节；视频编码、解码及抽帧检查记录见 GAMEPLAY_VIDEO.md。

## 后续录制结果

录制运行在固定30FPS下于研究所前被三名敌人围攻击败，MAINLINE_FAILED；没有将此运行计为通关通过。它产生了5239帧、约174.66秒的实际游戏画面，包含引擎输入引导性质标注。此前非录制发布运行的整章通过结果仍成立，但两次结果不一致，路线与控制器的稳定性尚未验证。

成功运行的真实存档已由新的发布EXE进程加载，mainline-restart.log 包含 MAINLINE_RESTART_OK，验证三设施、研究数据、基地及制作经验。视频将作为包含失败结果的实际流程演示，不是通关证明，也不是人工盲测。

0.21简略版：独立发布EXE在固定遭遇布局下从零完成主线和章节继续按钮，218.225秒，新进程恢复通过。没有传送、物资注入或禁用敌人。首次用旧QA档启动被新旅程确认挡住，测试工具已改为每次新建隔离配置；随后新配置旧随机敌群导致仓库途中死亡，这一失败促成了正式游戏遭遇布局调整。通过结果不等于首次体验时长、人工盲测或原计划完整验收。
