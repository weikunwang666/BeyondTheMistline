# 雾线之外 0.17 · 早期可玩版

Windows x64单人离线试玩。下载BeyondTheMistline-0.17-Windows.zip，完整解压后运行BeyondTheMistline.exe，保留同目录BeyondTheMistline.pck，无需安装Godot。

本版新增与修复：

- 敌人记住最后看见或听见的位置，失去视线后搜索，不继续追踪遮挡后的玩家新位置。
- G消耗一块石头投掷引诱，抛物线飞行检查碰撞，落点声响吸引尚未发现玩家的敌人。
- 菜单暂停石块飞行，新游戏和读档清除临时投石声响。
- 关闭菜单重新捕获鼠标时，短暂抑制镜头突跳。

验证：基础规则回归、独立发布EXE的实际绕墙/攻击预警/格挡、投石与感知受控测试，以及开局移动、采集、制作、背包拖拽、建造、退出和跨进程恢复均通过。属于引擎输入集成测试，不是人工盲测。

仍是开发原型：程序模型和动画尚未达到最终美术标准，人工长时游玩、首次30–60分钟体验与计划书最终验收尚未完成。此前0.16的一次引导流程完成主线，而固定30FPS录制在研究所前失败；本版没有将那次失败改记为通过，也未声称整章稳定复现。

源码包含Godot工程、素材来源和开发/测试脚本；引擎、模板、缓存、本地存档和编译产物不纳入源码历史。构建说明见docs/BUILDING.md，素材鸣谢见ASSET_CREDITS.md。
