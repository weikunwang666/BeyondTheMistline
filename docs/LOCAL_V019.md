# 0.19 美术与布局第一轮

立即优先进行画面布局，未等到所有玩法完成。HUD从单列堆叠文字拆为左上目标、右上地区/天气/潮位、左下生存条与状态、底部快捷栏。弹出菜单时隐藏世界HUD，避免背包和任务页透叠大量文字；交互准星和字幕保留独立位置。对提示文字增加暗底，提高浅色场景可读性。

湿地装饰从放大的普通草片改为原创芦苇网格，包含弯曲茎、叶片和褐色穗头，降低高度、形成疏密变化，清理栈道边缘2.2米范围。未改变地形、潮位、敌人或采集奖励。

基础回归及装备/背包布局检查通过。通过正常引擎渲染四张静态场景图检查HUD与植被，没有录屏，没有把受控场景截图当作实际游玩验收。上一轮已完成原生Windows设置、预设、滚动、保存返回与新游戏取消点击；本轮布局改动仍需发布版点击复查。
