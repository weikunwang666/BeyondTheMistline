# 雾线之外

当前交付：早期可玩版本 0.17，尚未通过 V2 计划书最终验收。

[下载 Windows 试玩版](https://github.com/weikunwang666/BeyondTheMistline/releases/tag/v0.17) · [从源码运行与构建](docs/BUILDING.md) · [已知限制](docs/KNOWN_ISSUES.md)

解压试玩包后双击 BeyondTheMistline.exe；源码工作区的运行文件位于 build 文件夹。必须保留同目录 BeyondTheMistline.pck。无需安装 Godot、Python 或其他开发依赖。主菜单选择“开始新的旅程”。

WASD 移动，鼠标转动镜头，Shift 冲刺，Ctrl 蹲伏，Space 跳跃，E 交互、采集或开关门，左键攻击，G 消耗一块石头投掷引诱。Tab 背包与制作，B 建造，R 旋转，右键取消建造，M 地图，J 任务，Esc 菜单。1–8 使用对应快捷物品。F5 保存。设置内可修改音量、灵敏度、视野和全屏。

0.2 新增 24 格背包：拖拽交换、同类合并，右键拆分，点击后使用、装备或丢弃。物品可拖至背包内的 8 格快捷栏重新分配。每格材料最多 20 件，工具每格 1 件；容量不足的物品保留在待领取输出区，腾出空间后领取。被丢弃的物品留在地面，可重新搜索取回。

石斧、木矛和弓需要装备才有效。石斧采集灰松需 3 次，徒手需 6 次；工具会损耗，损坏后移除。木矛与石斧提升近战伤害，弓消耗箭矢。火把装备后照亮周围。门框自带可开关的门，门状态、快捷栏、背包布局和耐久均保存。旧版存档在加载后自动迁移背包；建议新建一局体验新规则。

0.3 新增：墙与门框吸附地基边缘，屋顶对齐地基，延伸地基保持同一高度，陡坡拒绝放置。敌人使用粗网格路径搜索与近距碰撞探测，攻击前出现预警；正面对敌按住右键可格挡，消耗体力并减少伤害。M 打开图形地图，显示已发现地标和营地；左键添加标记、右键移除附近标记，标记会保存。森林营地、泵站和沉没港口新增可阅读的区域记录，首次阅读给予物资奖励，J 可查看收集进度。

0.4 更新：重制针叶树、风动草叶及角色肢体关节，修正角色行走朝向和帐篷屋顶，调整材质与昼夜天空。自建篝火使用燃料，E 打开管理界面；每份木材燃烧 120 秒，露天雨天加速消耗，熄灭后不能烤肉或保暖。集雨器降雨时每 30 秒积存一份水，容量 5 份。睡袋附近有敌人时不能睡眠，附近屋顶提高休息恢复。

初期建议：绕过海难残骸搜索漂流物资，制作石斧、木矛，采集树木和石头。前往渔村与伊莱交谈。东侧仓库有金属、零件、布料、饮水与食物。搭建篝火、工作台和睡袋，再按 J 中线索修复灯塔、研究所与山地通讯站。小心树林里的盐脊犬和湿地巨蟹。

自动存档每 45 秒触发，维修和放置建筑后也会保存。退出菜单可保存退出。存档位于 Windows 用户数据目录 Godot/app_userdata/雾线之外 Beyond the Mistline/mistline.json。开发测试使用独立的 tools/userdata 目录，不随试玩包分发。

0.5 存档改进：保存前校验结构，临时文件写完后回读校验，再替换主文件；上一份有效进度保存在 mistline.json.bak。主文件损坏时自动尝试备用文件并提示。两份都无法读取时保留原文件并停留在菜单。断电恢复仍未实测，请勿将备用文件视为完整备份策略。

0.6 世界更新：泵站西侧新增盐雾湿地、栈道、芦苇采集和巨蟹。沉没港口西侧木桩标记通向外礁货箱的旧石堤；潮位低于 -0.25m 时尝试穿越，高潮时深水会减速并造成伤害，先阅读岸边警示牌。HUD 显示当前潮位，J 记录货箱探索进度。地图由真实地形生成，并保存已探索范围。新区域改变了局部地形，建议新建游戏体验；旧存档原位置与建筑未自动重定位。

0.7 声音与设置：新增海浪、风、雨和森林声景，按区域、天气、昼夜渐变混合；沙地、草地、木面、金属、浅水脚步与采集、受击音效在世界位置播放。设置可保存音量、灵敏度、视野、反转 Y 轴、动态阴影、1280×720 / 1600×900 / 1920×1080 窗口分辨率及全屏。设置保存至用户目录 settings.cfg，与游戏进度分开。

0.8 生存与成长：C 查看疲劳、淋湿、中毒及五类技能。疲劳降低体力恢复，超过 70 限制最大体力；雨中淋湿加剧失温，屋顶防雨、篝火烘干。夜晚和高地更冷。生肉/河水直接食用有中毒风险；泵站提供河水，制作净水需要河水与滤芯。安全睡眠恢复疲劳，有屋顶时恢复更多。技能通过采集、实际制作、战斗和探索积累，影响对应效率与效果。

制作需要 4–8 秒，制作技能可缩短时间。点击配方后关闭背包开始制作，材料预先保留；Tab 可取消并返还。工作台和烹饪配方离开设施后暂停，返回后继续。制作进度随存档保存，满包产物进入待领取区。暂停菜单和背包会暂停整个世界及制作。

0.9 开局引导：HUD 根据实际进度提示收集材料、制作石斧、建造篝火、寻找净水和修复三处设施；已完成的初期步骤会保存，不因物品消耗而倒退。新增引擎输入流程测试，覆盖开局移动、搜索、配方点击、实际等待制作、快捷装备、背包拖拽、篝火放置/交互、菜单退出与独立进程恢复。这不替代原生桌面鼠标和完整人工游玩验收。

0.10 战斗更新：工具与武器挂在右手并随攻击动作运动；弓使用可见飞行箭矢，沿飞行路径检查墙体和目标碰撞。徒手、斧和矛使用不同近战距离，空弓不会消耗体力。加入近处敌人生命/攻击预警、受击反馈、跳跃/落地姿势、坠落伤害和短暂倒地后重生。死亡时在原地掉落随身物资和制作预留材料，基地与技能保留。

0.11 建造更新：新增楼梯（木材4），可吸附地基外侧；角色支持跨越小台阶，楼梯连接后可走入抬高地基。修复相邻地基与墙体接缝误判、设施不能放在地板上的问题。雨天遮蔽改为头顶真实屋顶检测，站在屋顶旁边不再算室内；房屋屋顶、原生建筑与帐篷可提供覆盖范围内的遮蔽。

0.12 寻路修复：导航网格从4米改为2米，并按敌人体积扩大障碍采样，避免薄墙从网格间漏过。局部避障改用身体前方探测，避免把正常坡地接触当成墙。已用动态巨蟹测试实际绕过墙体、接近、攻击预警，以及引擎右键输入下的正面格挡和体力扣除；复杂场景和两类敌人的全面实战仍待验收。

0.13 材质更新：接入六组 Poly Haven CC0 材质，区分沙地、森林地表、岩石、混凝土、旧木板和锈金属；物件使用漫反射/法线/粗糙度，地形按生态区混合，降雨时地面渐暗变湿。贴图随离线游戏分发，无需联网。作者、来源与使用方式见 ASSET_CREDITS.md。当前程序模型仍未达到最终美术标准。

0.14 性能更新：减少 HUD 重复提交、天空材质过频更新和音效逐采样计时调用。发布 EXE 在本机固定内部1080p、关闭VSync的七场景短测中，分区域平均约150–478 FPS；此结果不等于整局平均或最低配置承诺，详见 PERFORMANCE.md。普通窗口尺寸受系统DPI影响，基准入口另行校验实际渲染纹理大小。

硬件：已在 RTX 4050 Laptop GPU、NVIDIA 566.26、OpenGL 3.3 环境运行，1280×720。短时回归帧率读数约 100–140 FPS，不能视为长期平均值或 1080p 性能承诺。其他硬件尚未实测。

完整未完成项见 docs/KNOWN_ISSUES.md。工程入口 game/project.godot；技术选型见 docs/TECHNICAL_SELECTION.md；测试见 docs/TEST_REPORT.md。

0.15 支线更新：渔村药箱援助、泵站过滤修复与森林营地电台维修加入独立进度和一次性奖励。J查看状态，M查看任务位置。泵站修复后每40秒积存一份净水，最多5份；河水取用有30秒冷却。

0.16 主线与反馈：控制台、灯塔和通讯塔现在根据维修状态改变灯光。一次独立发布EXE的引擎输入引导流程从零采集并完成三处维修，约186秒，存档也已跨进程恢复。固定30FPS录制运行则在研究所前被击败，因此未宣称主线可稳定复现、人工盲测通过或首次体验达到30–60分钟。引导演示视频与其局限见 GAMEPLAY_VIDEO.md。


0.17 感知与潜行：敌人追踪最后目击位置，失去视线后搜索；G消耗石头制造落点声响，引开尚未发现你的敌人。抛物线飞行检测墙体碰撞，菜单暂停飞行，重新捕获鼠标时抑制镜头突跳。验证范围见 AI_PERCEPTION.md。工作区只保留最新发布包，源码、工具和存档独立保留。
